# 🔄 Telegram ⇄ Max Bridge Bot

Асинхронный мост-шлюз между группами в **Telegram** и чатами **Max**. Для него даже не нужен VPS, вы можете запустить его даже у себя на компьютере.

## 🤖 Команды Telegram-бота

| Команда | Описание |
| :--- | :--- |
| `/setname <Имя>` | Установить свое имя, отображаемое при отправке сообщений в Max. |
| `/myname` | Посмотреть текущее активное имя (кастомное или дефолтное). |
| `/delname` | Сбросить кастомное имя (снова использовать имя Telegram-профиля). |
| `/delete` | *(В ответ на свое сообщение)* Удалить сообщение из Telegram и из Max. |
| `/start` | Показать справочную информацию. |

## 📂 Структура проекта

```text
.
├── config.py           # Загрузка, типизация и валидация переменных окружения
├── database.py         # Работа с SQLite (сохранение маппинга ID, кастомные имена, авто-очистка)
├── max_client.py       # WebSocket-клиент протокола Max (прием, парсинг, отправка, файлы)
├── main.py             # Telegram-бот (Aiogram 3), обработка команд и связующий роутинг
├── requirements.txt    # Зависимости проекта
├── .env.example        # Пример файла конфигурации
└── database.db         # Локальная база данных SQLite (создается автоматически)
```
